Notes
- DRAM is idle (< 2.1%): the kernel is compute-bound; each 64-key K/V block is fetched once from DRAM and
  re-read by the 6 (GQA) x 16 (query blocks) = 96 CTAs that need it, so the L2 hit rate is ~1 - 1/96.
- BF16: one CTA (4 warps) per SM, i.e. one warp per scheduler (eligible warps 0.12-0.17).
- Tensor pipe 73.8% -> 64.3% with FP16-accumulate PV while the time drops 5.20 -> 4.50 ms: the ceiling
  moved. At 2.52 GHz QK (FP32 acc) and PV (FP16 acc) need 1.90 + 0.95 = 2.86 ms at peak; 2.86 / 4.50 = 63%.
- "split-KV build" = the intermediate development build with cluster split-KV only.
