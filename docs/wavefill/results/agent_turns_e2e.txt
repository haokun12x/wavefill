Agent turn latency, whole engine (tools/wavefill/agent_turns.cpp): Qwen3.8-27B NVFP4 artifact, BF16 KV,
1024-token prefill chunks, no speculative decoding, CUDA graphs, RTX 5090 (GPU otherwise idle), 2026-10-03.
For each (history H, delta d) a fresh conversation prefills H tokens untimed, then runs 1 warm-up and
3 measured turns; each turn = previous prompt + previous output + d new corpus tokens, 1 output token.
The engine reuses the previous endpoint (reused_prompt_tokens == history - 1 in every measured turn,
checked), so only d + 1 tokens are prefilled. before = commit 4b10b1c2 (NVFP4 GEMV only),
after = Wavefill HEAD; binaries alternated, 2 rounds -> 6 samples each. Median of the 6 samples.
ttft = first_token_seconds (request admission to first token). History grows by d+1 per turn, so the
spread of the larger deltas is mostly context growth (identical for before/after).
